Tronador CLI

Cross-platform automation for Cloud Ops Works workflows. Use Tronador to manage AWS resources, inspect IaC module pins, run project capabilities, and automate repository-template and release workflows.

Install Tronador · Browse all commands · View the source on GitHub

Get started

Install the latest stable release for your operating system, then check the available commands:

tronador --help
tronador version

The installation guide covers shell and PowerShell installers, Linux packages, Homebrew, Chocolatey, and release selection.
