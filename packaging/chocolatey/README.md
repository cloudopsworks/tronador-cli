# Chocolatey packaging

Chocolatey packaging is generated by the native `chocolateys` section of
`windows.goreleaser.yml`. The released executable and command are
`tronador.exe`/`tronador`; the package ID remains `tronador-cli`.
Do not use `internal/distribution` or `tools/distribution` generators.

The Windows GoReleaser pass creates and uploads `tronador-cli.<version>.nupkg`
to a draft GitHub release, but does not publish to the Chocolatey feed. Once
the default GoReleaser pass makes the GitHub release public, run
`packaging/chocolatey/publish.sh --version <version>`. It verifies the release
is non-draft, downloads that exact `.nupkg`, and pushes it with `choco` using
`CHOCOLATEY_API_KEY`. Never run this step before the release is public.

Primary validation:

```bash
goreleaser check --config windows.goreleaser.yml
packaging/chocolatey/test-native.sh
packaging/chocolatey/test-publish.sh
```
